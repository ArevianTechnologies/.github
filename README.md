## Editing

Keep image references relative to `profile/README.md`, and keep all visual assets in `profile/assets/`.
The SVG files must remain self-contained: no scripts, remote fonts, external images, or `foreignObject`.
Their text is outlined to keep the appearance consistent in GitHub's image renderer.

Use normal GitHub Markdown/HTML for the readable copy. Keep informative image alternatives and empty alternatives for purely decorative images.
Check the rendered README in GitHub and at a narrow mobile width, with both light and dark backgrounds.
